# Experience Foundry — Version 10

**Scaling Up Experiences**  
*Make the ordinary unforgettable.*

Version 10 is the polished static prototype prepared for sharing on GitHub Pages.

## Current pilot
The first real test is intentionally narrow: one Halloween 360° video experience for one apartment community. The 360° booth is supplied and operated by an independent professional rental company. Experience Foundry coordinates the concept, promotion, registration, vendor logistics, guest experience, and results reporting.

Costumes, decorations, props, candy, and other party materials are not supplied by Experience Foundry unless separately arranged by the host or another vendor.

## Preview locally
Open the folder in VS Code, trust the workspace, right-click `index.html`, and choose **Open with Live Server**.

## GitHub Pages
This site uses relative paths and is ready for GitHub Pages. Upload/push the contents of this folder to the root of a GitHub repository, then enable Pages from the `main` branch and `/ (root)` folder.
